# sysmgr — управляющий фреймворк ноды/флота

TUI-фреймворк управления сервером и флотом нод (дашборд, управление флотом,
шейпер трафика per-user, security-модули, gateway). **Вендоренная и
де-брендированная** замороженная копия стороннего инструмента — внешних
зависимостей при запуске нет, самообновление отключено.

## Установка

Через `relabel` (рекомендуется — ставит автоматически):

```bash
relabel sysmgr            # поставить (от root) → /opt/sysmgr + команда sysmgr
```

или напрямую:

```bash
sudo bash sysmgr.sh install
sudo sysmgr               # запустить TUI
```

`install` копирует код в `/opt/sysmgr` и создаёт команду `sysmgr`
(`/usr/local/bin/sysmgr`), затем выходит. Управление — интерактивно: `sysmgr`.

## Де-брендинг (что переименовано под нейтральную схему)

| Артефакт | Стало |
|---|---|
| каталог установки | `/opt/sysmgr` |
| команда | `sysmgr` (`/usr/local/bin/sysmgr`) |
| лог | `/var/log/sysmgr.log` |
| база флота | `~/.sysmgr_fleet` |
| SSH-ключи Skynet | `id_ed25519_sysmgr_*` |
| systemd/cron | `sysmgr-geoblock.*` и т.п. |
| самообновление | **отключено**, URL'ы апстрима очищены |

## Что осознанно осталось (не host-видимое / функциональное)

- Имена модулей `modules/remnawave/`, `modules/bot_bedolaga/` — внутри
  `/opt/sysmgr` (видно только при глубоком `ls`), переименовать нельзя без
  поломки фреймворка; ссылки на `remnawave` API — функциональные.
- TUI-баннер (ASCII-логотип, русский текст) — виден только оператору на
  экране, не является host-артефактом.

## Внимание

- Управляющий фреймворк, требует **root**. Локально (Linux/TUI) не
  прогонялся — проверены синтаксис и согласованность переименований.
- У исходника не было файла лицензии — используется как есть, на твоё усмотрение.
