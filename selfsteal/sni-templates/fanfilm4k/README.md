# FANFILM4K — selfsteal template

Страница-заглушка для Reality selfsteal: тёмный киносайт в стиле FanFilm4K
с несбрасываемым оверлеем «Идут технические работы» поверх контента.

- Один файл `index.html`, весь CSS/JS инлайн, **без внешних запросов**
  (не зависит от чужих CDN, ничего не «фонит» в сеть).
- Оверлей закрыть нельзя: нет кнопки, Esc/клик игнорируются, скролл заблокирован.

В этом форке это **единственный** шаблон, мутация (`RANDOMIZE_TEMPLATE`)
по умолчанию отключена, чтобы фирменный дизайн не перекрашивался.

Текст уведомления правится в блоке `<div class="maint">` файла `index.html`.
